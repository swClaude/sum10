# SUM10 パズル 仕様書 v1.0

## 0. 勝利条件
iPhone実機で「90秒・合計10消しパズル」が快適に遊べ、デイリー問題のスコアがGame Centerランキングに載り、広告と買い切り課金で収益が発生する状態でApp Storeに公開する。

## 1. コンセプト
- 画面は**90年代の社内業務システム／古い表計算ソフト風**。電車や職場でも「仕事の画面」に見える
- 中身は、長方形範囲を選んで合計10を作り消すパズル
- 1プレイ90秒。Game Centerでスコアを競う

## 3. 画面構成
```
起動 → ホーム ─┬→ デイリー（ランキング対象・1日1回）→ 結果
               ├→ タイムアタック（ランダム盤面・ランキング対象）→ 結果
               ├→ 練習（時間無制限・ランキング対象外）
               ├→ ランキング（Game Center UIを開く）
               ├→ ショップ（課金）
               └→ 設定
どの画面でも：2本指下スワイプ → ボス画面（もう一度で戻る）
```
| 画面 | 見た目の偽装名 | 要素 |
|---|---|---|
| ホーム | 「業務メニュー」 | 番号付きメニュー（1.日次照合 2.随時照合 3.研修 4.実績照会 5.購買 6.環境設定） |
| ゲーム | 「URIAGE.SHT」（実在ソフトの拡張子は使わない） | メニューバー／数式バー／グリッド／ステータスバー／シートタブ |
| 結果 | ダイアログ「処理が完了しました」 | 計上額・照合件数・内訳・自己ベスト・[OK][再実行][実績照会] |
| ショップ | 「ライセンス購入」 | 3商品＋購入の復元 |
| 設定 | 「環境設定」 | 効果音・振動・ボス操作・データ初期化・プライバシーポリシー |
| ボス画面 | 「月次売上レポート」 | 部門別の売上表と棒グラフ（ダミーデータ） |

## 4. ゲームルール
### 盤面
- 8列（A〜H）×12行。各セルには1〜9の整数が入る
- 数字の出現重み `W = [16,14,12,11,10,10,9,9,9]`（1→9の順）を `src/game/config.ts` で定数化する

### 操作と消去
- 長方形範囲を選択し、合計が**ちょうど10**なら指を離した時点で消える。10以外はキャンセル
- 消えたセルの上にある数字が落下して詰まり、上端の空きには新しい数字が補充される（重力あり）
- 落下アニメーションの間（約450ms）は入力を受け付けない
- **詰み防止**：盤面全体に合計10の長方形が1つも無ければ、盤面を全部作り直す（ステータスバーに「再計算中…」と表示）

### 得点（マス数別・`config.ts` で定数化）
| マス数 | 2 | 3 | 4 | 5以上 |
|---|---|---|---|---|
| 得点 | 10 | 30 | 70 | 150 |

- 表示は「計上額 ¥1,230」の形式
- 1マスで10は作れない（1〜9しかないため）

### 時間
- 90秒。残り10秒でバーが赤になり、1秒ごとに軽い振動
- 時間切れの時点で選択中の範囲は無効

### モード
| モード | 乱数シード | ランキング | 備考 |
|---|---|---|---|
| デイリー | JSTの日付 `YYYYMMDD` | 定期リセット型（1日） | 1日1回だけ本番。2回目以降は練習扱い |
| タイムアタック | ランダム | クラシック（歴代ベスト） | 何回でも挑戦可 |
| 練習 | ランダム | なし | 時間無制限。リワード広告でヒントを表示 |

- 乱数は seeded PRNG（mulberry32）を使う。初期盤面・補充・作り直しのすべてを**同じ乱数列**から順に取り出す。これにより、同じ日のデイリーは全員が同じ盤面・同じ補充順になる

## 5. 操作仕様（iPhone最優先）
- セル：幅45pt以上（(画面幅 − 行番号28pt) ÷ 8）。高さも同じ値
- 選択はセル単位で吸着する。始点セルと現在のセルを対角とする長方形
- 選択範囲が変わるたびに、数式バーに `=SUM(B3:C4)` と合計値を表示する（指で隠れない上部に置く）
- ハプティクス
  - 選択範囲が変わった：`selectionAsync`
  - 合計が10になった瞬間：`impactAsync(Light)`
  - 消去：`notificationAsync(Success)`
- 効果音はデフォルトOFF（設定でON可）
- ボス画面：2本指で下スワイプ（60pt以上）。設定で「3本指タップ」にも変更可
- アプリがバックグラウンドへ移ったら自動で一時停止し、ボス画面を表示する（アプリ切替画面のサムネイルでもバレない）

## 6. デザイン仕様（レトロ業務システム風）
方針：**90年代にエンジニアが自作した社内ツール**の雰囲気。立体的なグレーのボタン、紺色のタイトルバー、ドットフォントを使う。実在OSやソフトのロゴ・アイコン・製品名は使わない。

### カラートークン（`src/ui/theme.ts`）
| トークン | 値 | 用途 |
|---|---|---|
| face | `#C0C0C0` | ウィンドウ・ボタンの面 |
| hilight | `#FFFFFF` | 立体枠の左上 |
| shadow | `#808080` | 立体枠の右下（内側） |
| dark | `#000000` | 立体枠の右下（外側） |
| title | `#000080`→`#1084D0` | タイトルバー（横グラデーション） |
| cell | `#FFFFFF` | セル背景 |
| grid | `#C0C0C0` | 罫線 |
| select | `#000080` | 選択範囲（白抜き文字） |
| hit | `#008080` | 合計10の範囲 |
| danger | `#800000` | 残り10秒 |

### 部品
- **立体枠**：凸（ボタン・ウィンドウ）＝左上白・右下黒の2px枠。凹（入力欄・グリッド外枠）＝色を逆にする。`<Bevel type="raised|sunken">` として共通コンポーネント化
- **タイトルバー**：高さ22pt・白文字の太字。右端に `_ □ ×` 風の飾りボタン（×はホームへ戻る）
- **メニューバー**：`ファイル(F) 編集(E) 表示(V) 挿入(I) 書式(O)`。飾りだが、タップするとそれっぽいドロップダウンを出す（中身は「一時停止」「ホームへ」「ボス画面」）
- **セル選択**：Windows 9x風の反転表示（紺背景・白文字）。合計10の範囲は青緑背景
- **フォント**：UI全体は DotGothic16。数字も同じフォントで右寄せ
- **アニメーション**：派手にしない。消去は2フレームの点滅、落下はイージングなしの等速＋着地で1px沈む
- **結果ダイアログ**：`i` アイコン付きの古いメッセージボックス風
- **アプリアイコン**：グレーの立体枠の中に「Σ10」のドット絵

参考画面：`docs/design-mock.html`

## 7. Game Center
### App Store Connect の設定
- App IDで Game Center を有効にする
- リーダーボード
| ID | 種類 | 設定 |
|---|---|---|
| `sum10.daily` | 定期リセット型 | 開始日の00:00 JST・期間1日・高い順・整数・範囲0〜30000 |
| `sum10.timeattack` | クラシック | 高い順・整数・範囲0〜30000 |
- 表示名（日本語・英語）と、得点の単位「円」を設定する
- **最初の申請バージョンにリーダーボードを紐づける**（忘れると公開後に表示されない）

### Nativeモジュール API（`modules/game-center`）
```ts
authenticate(): Promise<{ isAuthenticated: boolean; displayName?: string }>
submitScore(score: number, leaderboardIds: string[]): Promise<void>
showLeaderboard(leaderboardId?: string): Promise<void>
```
- 起動時に `authenticate`。失敗・未ログインでもゲームは遊べる（ランキングに載らないだけ）
- 送信に失敗したらMMKVのキューに保存し、次回起動時に再送する
- デイリーは本番1回目のスコアだけを送る

## 8. 広告（AdMob）
| 種類 | 表示タイミング | 条件 |
|---|---|---|
| インタースティシャル | 結果ダイアログを閉じた後 | 2プレイに1回・前回表示から60秒以上空ける |
| バナー | ホーム・結果画面の下部 | **プレイ中は出さない**（誤タップ防止・AdMobポリシー対策） |
| リワード | 練習モードのヒント（10になる範囲を3秒間点滅） | 1回の練習につき3回まで |

- 起動時の初回にATTの許可ダイアログを出す。事前に説明画面を1枚挟む
- 開発中はテスト広告IDを使う（`__DEV__` で切り替え）

- スキン：標準（グレー）／黒画面端末風（緑文字）／帳票風（連続用紙の緑帯）／英語UI

## 13. テスト観点
- 選択範囲：逆方向ドラッグ／盤面の外に出た指／1マスだけの選択／落下中のタップ
- 境界：時間切れと消去が同時に起きる／バックグラウンドへ移る／日付変更の瞬間（23:59→0:00 JST）
- デイリー：端末の時計をずらす（JSTで判定）／機内モードで送信→キューに入って後で再送
- 課金：機内モードでの購入／復元／返金された後
- 盤面：詰み判定から作り直しまでの間に操作する

## 15. 既知のリスク
- **Swiftモジュールのビルド失敗がEASのログでしか分からない**（Windows環境のため）→ APIは3関数だけに絞り、先にフェーズ5単体でビルドを通す
- **デイリー問題の攻略が共有される** → 1日1回制限と、補充が操作順に依存するため、完全なコピーは難しい
- **スコア改ざん** → Game Centerのスコア範囲の上限で弾く。完全な防止はしない（サーバー無し方針のため）
- **レトロUIだと現代のスマホ画面として浮く** → 「古い社内システム」はむしろ仕事感があるという判断。反応が悪ければスキンで現代風を追加する
